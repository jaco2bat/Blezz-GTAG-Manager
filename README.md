This is a simple tool to help you manage your Gorilla Tag game on Windows. It gives you a menu where you can:

Open the Gorilla Tag folder

Access the plugins folder to add mods

Launch the game through Steam

Change the game’s file path if needed

The script automatically checks for the game folder and uses the default Steam location if it can’t find it. It’s made to make managing files and plugins easier without having to hunt through your computer. Just run the batch file and follow the menu!
